![Vercel](https://img.shields.io/badge/Deployed%20on-Vercel-black?logo=vercel)

Signalist is a full-stack, production-ready stock market application designed to provide users with tools to track market shifts, receive personalized AI-driven alerts, and explore detailed company insights.



## ✨ Key Features

* **Real-Time Market Data**: Integrated Trading View widgets for live candlestick charts, market overviews, heat maps, and watch lists.
* **Powerful Stock Search**: A debounced, fast search functionality (invoked with `Ctrl+K` / `Cmd+K`) powered by the Finnhub API.
* **Secure Authentication**: Robust email and password authentication using **Better Oath**, complete with protected routes and session management.
* **AI-Powered Personalization**:
    * **Personalized Welcome Emails**: New users receive a unique welcome email generated by **Google Gemini**, tailored to their investment goals and preferences.
    * **AI-Summarized Daily News**: A daily cron job fetches relevant news based on a user's watch list, summarizes the articles using AI, and delivers a personalized digest.
* **Modern & Responsive UI**: A sleek, professional dark-theme UI built with **Shadcn** and **Tailwind CSS**, optimized for data visualization.
* **Scalable Background Jobs**: Leverages **Ingest** to handle real-time workflows, triggers, and AI automation without impacting user experience.

## 🚀 Architectural Highlights & Implementation Details

### Application Structure
The project uses Next.js **Route Groups** to create distinct layouts for different parts of the application without affecting the URL structure.
* `(root)`: Contains the main application pages (dashboard, search, etc.) that share a common `Header`.
* `(auth)`: Contains the `sign-in` and `sign-up` pages, featuring a split-screen layout for a focused authentication experience.

### Authentication Flow
Authentication is handled via **server actions** and **Better Oath**, which seamlessly integrates with the MongoDB adapter to manage user and session collections.
* **Singleton DB Connection**: To prevent multiple database connections during development hot-reloads, a singleton instance with a global cache is used for the Mongoose connection.
* **Protected Routes**: A `middleware.ts` file checks for a valid session cookie, redirecting unauthenticated users to the sign-in page.

### AI-Powered Workflows with Ingest 🧠
**Ingest** is the backbone of our asynchronous and AI-driven features, ensuring the application remains fast and responsive.

1.  **Personalized Welcome Email**:
    * **Trigger**: The `app/user.created` event is sent to Ingest upon successful user sign-up.
    * **Action**: Ingest constructs a detailed prompt using the user's provided data (country, investment goals).
    * **AI Inference**: The `step.ai.infer` function calls **Google Gemini (2.5 Flash Light)** to generate a personalized HTML welcome message.
    * **Delivery**: **NodeMailer** sends the generated email to the user.

2.  **Daily News Summary**:
    * **Trigger**: A cron job (`sendDailyNewsSummary`) runs daily at 12:00 p.m. UTC. It can also be triggered manually.
    * **Action**: The workflow fetches users and their watch lists, then retrieves relevant news from the **Finnhub API**.
    * **AI Summarization**: Ingest's AI capabilities are used to summarize the articles into a concise, personalized digest.
    * **Delivery**: The summarized news is emailed to users via NodeMailer, with Ingest handling automatic retries on failure.

### Development & Deployment Practices
* **AI Code Reviews**: The repository is integrated with **Code Rabbit**, which provides automated, in-depth AI code reviews on every pull request. It generates sequence diagrams for server actions, detects potential bugs, and suggests refactoring opportunities.
* **Deployment**: The application is deployed on **Vercel**, with seamless integration for Next.js features and Ingest workflows.

## 🏁 Getting Started

To get a local copy up and running, follow these simple steps.

### Prerequisites

* Node.js (v18.0 or later)
* npm, yarn, or pnpm
* Git

### Installation

1.  **Clone the repository:**
    ```sh
    git clone [https://github.com/your-username/signalist-stock-app.git](https://github.com/your-username/signalist-stock-app.git)
    ```
2.  **Navigate to the project directory:**
    ```sh
    cd signalist-stock-app
    ```
3.  **Install NPM packages:**
    ```sh
    npm install
    ```
4.  **Set up your environment variables:**
    * Create a `.env.local` file in the root of the project by copying the example file:
        ```sh
        cp .env.example .env.local
        ```
    * Fill in the required API keys and connection strings in `.env.local`:
        ```env
        # MongoDB
        MONGODB_URI="your_mongodb_connection_string"

        # Finnhub API
        FINNHUB_API_KEY="your_finnhub_api_key"

        # Ingest
        INGEST_EVENT_KEY="your_ingest_event_key"
        INGEST_SIGNING_KEY="your_ingest_signing_key"

        # Nodemailer (using Google SMTP)
        GOOGLE_SMTP_USER="your_email@gmail.com"
        GOOGLE_APP_PASSWORD="your_google_app_password"

        # Better Oath Secret
        AUTH_SECRET="generate_a_strong_secret_key"
        ```

5.  **Run the development server:**
    ```sh
    npm run dev
    ```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.
